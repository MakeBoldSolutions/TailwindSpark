# .archive/

Committed, permanent history — **never gitignored**. Holds work products harvested off completed features (`bold.ship harvest`): task lists, resolved critiques, clarification Q&As, superseded revisions.

**Human consumption only.** No agent, command, or script reads this directory, ever — not even when a human explicitly points at a file in it. It lives at the repo root, not under `bold-docs/`, so that rule is a directory boundary rather than a convention inside a tree agents otherwise read freely. `bold.ship harvest` is the only command that ever writes here.

Browse freely; deletion is a low-stakes, human-scheduled decision (nothing in here is ever regenerated). See `index.md` for what was archived, when, and what it promoted into `bold-docs/system/`.
