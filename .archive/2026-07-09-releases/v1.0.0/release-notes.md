## Highlights

This baseline release establishes TailwindSpark's first formal release archive and captures the repository's completed multi-theme platform work as a durable project milestone. The release documents the transition from a light/dark-only design system to a named, interchangeable theme architecture that preserves application behavior while materially expanding the presentation model.

The shipped platform introduces material, minimal, and brutalist design systems with light and dark variants, semantic token layering, first-paint theme restoration, and rollout recovery behavior for service-worker-controlled sessions. Shared primitives and high-visibility application surfaces now consume a common presentation contract, which reduces styling drift and makes future theme additions additive instead of structural rewrites.

This release also promotes the most important implementation decisions into ADRs so the repository has a stable record of why named theme activation, CSS-first semantic tokens, and cache-safe theme rollout behavior were chosen.

## New Features

### Multi-Theme Design System Platform

TailwindSpark now supports interchangeable named design systems without changing application structure or feature behavior. The platform preserves existing user journeys while enabling materially different visual languages across shared components and route-level surfaces.
