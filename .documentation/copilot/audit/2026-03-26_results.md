## Findings

### DOC1 - Harvest automation misclassifies active docs

**Constitution reference**: Principle V requires documentation to remain current and accurate.

**Evidence**:

` .documentation/scripts/powershell/harvest.ps1 `

```powershell
} elseif ($docRoot.mode -eq 'legacy') {
    $category = 'legacy_root_doc'
}
```

Current scan output archived as evidence in `.documentation/copilot/preharvest-doc-audit-2026-03-26.json` showed `docs/ARCHITECTURE.md`, `docs/BRANDING.md`, `docs/CHANGELOG.md`, `docs/DEPLOYMENT.md`, `docs/GETTING_STARTED.md`, and `docs/TESTING.md` classified as archive candidates even though `.archive/README.md` explicitly defines `docs/` as an active documentation surface.

**Why this violates the principle**:

The automation produces stale-reference noise and unsafe archive recommendations, which directly undermines documentation correctness during harvest review.

**Recommendation**:

Treat `docs/` as live by default in this repository and gate `legacy_root_doc` classification behind a repository-specific signal rather than a broad mode switch.

### DOC2 - Archive agent references non-existent live targets

**Constitution reference**: Principle V requires the active documentation process to stay current.

**Evidence**:

` .github/agents/speckit.archive.agent.md `

```markdown
Before moving anything, extract important information into `CHANGELOG.md` and `.documentation/Guide.md` so no knowledge is lost.

**CRITICAL: Never read from `.archive/` during this command or any other command.**
```

Later in the same file:

```markdown
The changelog lives at `CHANGELOG.md` (repo root).
The guide lives at `.documentation/Guide.md`.
```

Verified repo state:

- Live changelog is `docs/CHANGELOG.md`
- `.documentation/Guide.md` does not exist
- `.archive/README.md` is itself an active policy document that must sometimes be read to avoid bad archive decisions

**Why this violates the principle**:

The operational instructions point to non-existent targets and forbid consulting the very policy source that defines what stays live, which creates process drift and incorrect archive behavior.

**Recommendation**:

Update the archive agent to use `docs/CHANGELOG.md`, replace `.documentation/Guide.md` with the actual living guide location if one exists, and allow `.archive/README.md` or equivalent policy files to be read when validating archive decisions.
