| C1 | VII. Monorepo Architecture (MANDATORY) | apps/demo-app/src/main.tsx:11 | The stale-runtime recovery path deletes origin-global browser state, not just TailwindSpark state. `sessionStorage.clear()` and `caches.keys().map(cacheName => caches.delete(cacheName))` in [apps/demo-app/src/main.tsx](apps/demo-app/src/main.tsx#L11) will wipe all session storage keys and all Cache Storage entries for the current origin when a version mismatch is detected.
